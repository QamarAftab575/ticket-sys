📖 Product Overview

Tasqo is a modern, full-featured project management and team collaboration platform built with cutting-edge technologies. Designed for scalability and performance, it supports millions of daily users with a clean, intuitive interface and powerful features.

Whether you're managing a small team or coordinating across multiple departments, Tasqo provides all the tools you need to plan, track, and deliver projects successfully.

🚀 Installation Guide

Step 1: Upload Files

Upload all files to your server's web root directory (e.g., public_html, www, or httpdocs).

Step 2: Database Setup

Create a new MySQL database and user:

CREATE DATABASE tasqo_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER 'tasqo_user'@'localhost' IDENTIFIED BY 'strong_password_here'; GRANT ALL PRIVILEGES ON tasqo_db.* TO 'tasqo_user'@'localhost'; FLUSH PRIVILEGES;

Step 3: Environment Configuration

Configure your .env file with the following essential settings:

# Application APP_NAME=Tasqo APP_ENV=production APP_DEBUG=false APP_URL=https://yourdomain.com # Database DB_CONNECTION=mysql DB_HOST=127.0.0.1 DB_PORT=3306 DB_DATABASE=tasqo_db DB_USERNAME=tasqo_user DB_PASSWORD=strong_password_here # Mail Configuration MAIL_MAILER=smtp MAIL_HOST=smtp.gmail.com MAIL_PORT=587 MAIL_USERNAME=your-email@gmail.com MAIL_PASSWORD=your-app-password MAIL_ENCRYPTION=tls MAIL_FROM_ADDRESS=noreply@yourdomain.com MAIL_FROM_NAME="Tasqo" # Stripe Payment STRIPE_KEY=pk_live_xxxxx STRIPE_SECRET=sk_live_xxxxx SITE_CURRENCY=usd SITE_CURRENCY_SIGN=$ # Trial Configuration FREE_TRIAL_FOR_NEW_USERS=10 WORKSPACE_FOR_TRIAL_USERS=1 PROJECT_PER_WORKSPACE_FOR_TRIAL_USERS=5 MEMBERS_PER_PROJECT_FOR_TRIAL_USERS=10 BONUS_DAYS_AFTER_LIMIT=2

Step 4: Install Dependencies

Run the following commands via SSH:

# Install PHP dependencies composer install --optimize-autoloader --no-dev # Install JavaScript dependencies npm install # Build frontend assets npm run build # Generate application key php artisan key:generate # Run database migrations php artisan migrate --force # Link storage directory php artisan storage:link # Clear and cache configuration php artisan config:cache php artisan route:cache php artisan view:cache

Step 5: Set Permissions

Set proper file permissions:

chmod -R 755 storage bootstrap/cache chown -R www-data:www-data storage bootstrap/cache

Step 6: Web Installer (Alternative)

If you prefer a visual installer, visit https://yourdomain.com/install and follow the on-screen instructions.

💡 Web Installer Includes:
  • Requirements checker
  • Database configuration
  • Admin account creation
  • Automatic migration & seeding

Step 7: Queue Worker Setup (Production)

For email notifications and background jobs, set up a queue worker with Supervisor:

# Create Supervisor configuration sudo nano /etc/supervisor/conf.d/tasqo-worker.conf # Add this configuration: [program:tasqo-worker] process_name=%(program_name)s_%(process_num)02d command=php /path/to/tasqo/artisan queue:work --sleep=3 --tries=3 autostart=true autorestart=true user=www-data numprocs=2 redirect_stderr=true stdout_logfile=/path/to/tasqo/storage/logs/worker.log # Reload Supervisor sudo supervisorctl reread sudo supervisorctl update sudo supervisorctl start tasqo-worker:*

Step 8: Create Super Admin

After installation, register the first user account. Then, manually set them as super admin in the database:

UPDATE users SET is_super_admin = 1 WHERE email = 'admin@yourdomain.com';

Step 9: Configure Stripe

  1. Log in to your Stripe account
  2. Get your API keys (Publishable & Secret)
  3. Add them to your .env file
  4. Test payment in admin panel

Step 10: Post-Installation Tasks

  • ✅ Create subscription plans in admin panel
  • ✅ Configure email settings and send test email
  • ✅ Set up Google OAuth (optional)
  • ✅ Add additional languages (optional)
  • ✅ Configure trial limits
  • ✅ Test complete user flow (signup → trial → subscription)

💳 Payment Gateway & Billing System

Payment Integration

Payment Gateway: Stripe (Latest PHP SDK)

Tasqo uses Stripe Checkout for secure, PCI-compliant payment processing. No sensitive card data touches your server.

Payment Flow

  1. User selects a subscription plan
  2. System creates a secure payment token
  3. User is redirected to Stripe Checkout (hosted page)
  4. User completes payment securely on Stripe
  5. Stripe redirects back with payment confirmation
  6. System verifies payment token and session
  7. Subscription is activated automatically
  8. User receives confirmation email
