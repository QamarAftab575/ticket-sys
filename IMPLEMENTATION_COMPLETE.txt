## HOW IT WORKS (SIMPLIFIED):

1. User loads any page
   ↓
2. AppLayout.vue mounts
   ↓
3. fetchSubscriptionStatus() called
   ↓
4. API: GET /api/subscription/expiry-status
   ↓
5. Backend: BillingHelper::getExpiryStatus($user)
   ↓
6. Calculate: status, message, days_remaining, days_in_grace_period
   ↓
7. Return JSON response
   ↓
8. Frontend stores in subscriptionStatus ref
   ↓
9. Pass to AppSidebar component
   ↓
10. Sidebar displays alert based on status
    - status='warning' → Yellow "Expiring Soon"
    - status='expired_grace' → Orange "Grace Period"
    - status='suspended' → Red "Suspended"

## STATUS STATES:

Active (days > 0)
├─ User can use system normally
├─ No warnings shown
└─ No restrictions

Warning (days = 0)
├─ Show yellow "Expiring Soon" alert
├─ User can still use system
├─ Prompt to renew
└─ After 1 day → Expired

Grace Period (0 > days > -grace_period_days)
├─ Show orange "Grace Period" alert
├─ Countdown timer shows days left
├─ User can still use system (if owner of workspace)
├─ Redirect to /settings/subscriptions (if owner tries workspace)
└─ After grace period → Suspended

Suspended (days < -grace_period_days)
├─ Show red "Suspended" alert
├─ Owners: Blocked from workspaces, redirected to /settings/subscriptions
├─ Members: Blocked from owner's workspaces, see suspension notice
└─ Until renewed

Inactive (no subscription/trial)
├─ No alert shown
├─ No active subscription or trial
└─ Cannot create workspaces (blocked by other limits)
